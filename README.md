# Smart Home Automation System

An ESP32-based Smart Home Automation System designed to control
home appliances remotely and automatically.

## Features

- 8-channel appliance control
- ESP32 based system
- Blynk app control
- Firebase Realtime Database
- Temperature & humidity monitoring
- Gas detection
- Fire detection

## Hardware Used

- ESP32 38-Pin
- 8-Channel Relay Module
- DHT22
- MQ Gas Sensor
- Fire Sensor
- Buzzer

## Technologies

- Arduino IDE
- C/C++
- ESP32
- Firebase Realtime Database
- Blynk IoT
